# OpenAgent Tools

Independent, reusable filesystem, editor, shell, web search and device
capabilities. Hosts may call them as Python packages, expose them through the
neutral tool protocol or register them as MCP servers where supported.

Start with [docs/README.md](docs/README.md). The public capability guide is at
[openagent.uno](https://openagent.uno/guide/mcp), and the verified beta artifacts
are published in
[`v1.0.0-beta.1`](https://github.com/openagent-uno/openagent-tools/releases/tag/v1.0.0-beta.1).
