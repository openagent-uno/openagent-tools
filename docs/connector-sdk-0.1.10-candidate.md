# SDK 0.1.10 patch qualification

[SDK 0.1.10](https://github.com/openagent-uno/openagent-tools/releases/tag/connectors-v0.1.10) is published from source `db0f76941b8b9dd25b36502c765c84630e459dd2` after canonical remote qualification. Its [receipt](connector-sdk-0.1.10-qualification.json) binds all 11 public assets, anonymous downloads, Go Proxy provenance and Linux native execution. It includes the bounded Postiz provider-failure propagation already reviewed on main. The catalog remains 114 official connectors plus Custom MCP, with the same 315 read and 82 action operations, schemas, permissions and authentication contracts as SDK 0.1.9.

Postiz failures preserve only the existing finite error kind and validated HTTP status. Raw messages, provider request identifiers, headers, credentials and response bodies remain redacted. Unknown kinds and mismatched statuses retain the generic failure. The synthetic no-expiry OAuth fixture also verifies the fixed integrations endpoint and raw Authorization credential contract; it does not prove account entitlement or live provider access.

The canonical qualifier retains every SDK 0.1.9 cohort, source Python catalog parity, privacy, native metadata and acquisition guard. Qualification passed sequential tests/race, vet, vulnerability checks, six-platform runner/auth builds, the Python wheel, source provenance and checksums, and Linux native/installed checks. All 11 published files were downloaded anonymously and verified byte-for-byte; the public Linux bundle produced the expected catalog. Cross-compilation does not establish native macOS or Windows execution.

No provider calls, new grants, account trials or subscriptions are part of this release qualification. SDK 0.1.9 and its immutable receipts remain historical. A product must explicitly adopt this version; publishing this SDK does not update an installed server or CLI.
